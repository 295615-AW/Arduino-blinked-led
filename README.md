# Arduino-blinked-led
Prosty projekt z Arduino, migająca dioda w odstępie 1 sekundy.
Mój pierwszy projekt, łączący Arduino z Gitem.

## Potrzebne części
- Arduino Uno
- kabel USB A -> USB B

## Jak uruchomić program?
1. Otwórz `blinked_led/blinked_led.ino` w Arduino IDE
2. Wybierz płytkę (Tools -> Board) oraz port (Tools -> Port)
3. Kliknij strzałkę - Upload

## Czego się nauczyłam?
- praca z Gitem (podstawowe komendy)
- praca z GitHubem - repozytorium i struktura projektu
